# Uso de IA na equipe

Como a equipe aplica a [política de IA da disciplina](/docs/disciplina#política-de-ia)
no dia a dia e onde fica a evidência que a R2 e a R3 cobram ("o que foi aceito e
o que foi rejeitado").

:::caution[A preencher pela equipe]
Os combinados abaixo precisam ser decididos pelo time (planning ou retrospectiva)
e registrados aqui. Esta página não pode ser escrita por IA: ela é a reflexão
da própria equipe. Responsáveis sugeridos: líderes da quinzena 5, até 26/10.
:::

## Combinados

| Tema | Combinado da equipe | Desde |
| --- | --- | --- |
| Onde cada pessoa mantém o seu `MD_Template.md` e com que frequência atualiza | | |
| Como um PR sinaliza uso relevante de IA (label, seção no template de PR, `Co-authored-by`) | | |
| Quem revisa código gerado por IA antes do merge (a revisão não pode ser feita por IA) | | |
| O que nunca passa por IA (atas com o PO, decisões gerenciais, aprovação de PR) | | |
| Como consolidamos os aprendizados para "Como usamos IA neste semestre" (R3) | | |
