# Atividade 2

## É/Não É - Faz/Não Faz (ENFN)

Nesta atividade, busca-se delimitar e caracterizar o produto a partir de quatro diretrizes. O ENFN utiliza uma dinâmica simples para estabelecer de forma clara **o que o produto é**, **o que o produto não é**, **o que o produto faz** e **o que o produto não faz**. Essa definição contribui para o alinhamento entre os participantes, permitindo estabelecer uma compreensão comum sobre a finalidade, as características e os limites do produto.

A partir dessa classificação, é possível reduzir ambiguidades sobre a solução e auxiliar na definição de seu escopo, servindo como referência para as demais etapas da Lean Inception e para as decisões relacionadas ao desenvolvimento do produto.

## Descrição

Nesta atividade, foi realizada a elaboração e revisão da agenda do produto de forma colaborativa com os participantes. Por se tratar da continuidade de um projeto desenvolvido em semestres anteriores, foram inicialmente revisados os cards referentes às contribuições e funcionalidades já levantadas anteriormente, buscando preservar os pontos ainda pertinentes ao contexto atual do produto.

Além disso, foram incorporados novos cards relacionados às funcionalidades de Inteligência Artificial (IA) previstas para esta etapa do projeto. Dessa forma, a agenda consolidou tanto os elementos já existentes quanto as novas necessidades identificadas, servindo como base para o planejamento e a condução das atividades subsequentes da Lean Inception.
