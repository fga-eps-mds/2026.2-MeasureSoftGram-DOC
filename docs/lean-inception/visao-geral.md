# Lean Inception 2026.2

Resultado da Lean Inception de 2026.2, feita com o PO para decidir o que entra no
MVP e em que ordem. Por ser a continuação de um produto de semestres anteriores,
a equipe partiu do quadro de 2026.1 e marcou o que foi **mantido**, **mudado** ou
é **novo**.

| Atividade | Resultado em uma linha |
| --- | --- |
| [1. Visão do produto](/docs/lean-inception/visao-do-produto) | Visão de 2026.1 mantida, com a integração ao fluxo do desenvolvedor (plugins, CLI, IA) como diferencial |
| [2. É / Não é / Faz / Não faz](/docs/lean-inception/e-nao-e-faz-nao-faz) | Não é IA generativa nem ferramenta de score; disponibilização do plugin VS Code marcada para retirar |
| [3. Objetivos](/docs/lean-inception/objetivos) | Quatro objetivos: quantificar indicadores, comparar planejado × release, análise temporal e integração com outras ferramentas |
| [4. Personas](/docs/lean-inception/personas) | Personas de 2026.1 mantidas; MVP foca em Valéria, Helena e Miguel |
| [5. Jornadas](/docs/lean-inception/jornadas) | Jornadas refeitas do zero (as de 2026.1 foram consideradas inadequadas pelo professor) |
| [6. Brainstorming](/docs/lean-inception/brainstorming) | Novas funcionalidades: GitLab, novos indicadores, gráficos, relatórios |
| [7. Revisão técnica, de negócio e UX](/docs/lean-inception/revisao-tecnica-negocio-ux) | Funcionalidades de análise multimodelo e Action via LLM descartadas |
| [8. Dimensionamento](/docs/lean-inception/dimensionamento) | Tamanhos P/M/G convertidos em tempo para estimar as ondas |
| [9. Sequenciador](/docs/lean-inception/sequenciador) | Cinco ondas; MVP = ondas 1 a 3 (Releases 1 a 3) |
| [10. Canvas MVP](/docs/lean-inception/canvas-mvp) | MVP com 10 funcionalidades, entrega em 07/12/2026 e custo estimado de 252 horas |
