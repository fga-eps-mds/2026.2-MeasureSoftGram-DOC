## Sobre o MeasureSoftGram

O MeasureSoftGram é uma plataforma de medição e avaliação de qualidade de
software. Ele coleta métricas de repositórios, aplica um modelo de qualidade
configurável e apresenta o resultado de forma comparável ao longo do tempo.

A documentação **do produto** (como usar, referência da CLI, componentes) vive em
repositório próprio: [MeasureSoftGram-Docs](https://fga-eps-mds.github.io/MeasureSoftGram-Docs/).
Este site trata do **trabalho da equipe na disciplina**.

## Como a equipe se organiza

Diferente de 2026.1, que se organizou em **clãs por repositório**, em 2026.2 a
equipe trabalha com **squads temporários por onda/release**: cada squad pega uma
fatia vertical de funcionalidade e mexe em quantos repositórios forem necessários
para entregá-la ponta a ponta. O racional e a alocação estão em
[Squads por release](/docs/planejamento/squads).

## Como contribuir com esta documentação

O site é gerado com [Docusaurus](https://docusaurus.io/) a partir dos arquivos
Markdown em `docs/`. Para rodar localmente:

```bash
yarn install
yarn start
```

Cada página tem um link **Edit this page** no rodapé que leva direto ao arquivo
correspondente no GitHub. Alterações na branch `main` são publicadas
automaticamente pelo workflow do GitHub Pages.
