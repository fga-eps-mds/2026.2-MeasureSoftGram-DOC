2026.2** no **MeasureSoftGram**: o que planejamos, o que entregamos em cada
release e com quais evidências. A documentação **do produto** (como usar, CLI,
componentes) fica em [MeasureSoftGram-Docs](https://fga-eps-mds.github.io/MeasureSoftGram-Docs/).

## Como a equipe se organiza

Em 2026.2 a equipe trabalha com **squads temporários por release**, cada um
responsável por uma fatia vertical de funcionalidade em quantos repositórios
forem necessários (em 2026.1 eram clãs por repositório). Ver
[Squads por release](/docs/planejamento/squads).

## Como contribuir

Siga o [Guia de documentação](/docs/equipe/guia-documentacao): modelo de página,
onde registrar cada coisa e checklist de revisão. Para rodar o site localmente:

```bash
npm ci
npm start
```

Cada página tem o link **Editar esta página** no rodapé. O que entra na `main` é
publicado automaticamente no GitHub Pages.
