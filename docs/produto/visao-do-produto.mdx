# Visão do Produto

Documento inicial de alinhamento sobre o propósito do MeasureSoftGram no semestre
2026.2, combinando o [diagnóstico](/docs/diagnostico) dos repositórios legados, as
definições da [Lean Inception](/docs/lean-inception/visao-geral) e a validação do
Product Owner.

## Propósito

O MeasureSoftGram é uma plataforma para **gestão contínua da qualidade de
software**. Ele consolida métricas extraídas de ferramentas de análise estática
(como o SonarQube) e as traduz em um modelo matemático hierárquico
(características, subcaracterísticas e medidas), gerando o indicador global de
qualidade **TSQMI** (*Total Software Quality Measure Index*).

Para a disciplina de Engenharia de Produto de Software (2026.2), o produto
compara os objetivos de qualidade planejados com o que foi desenvolvido em cada release,
apoiando a decisão de aceitação da release dentro do fluxo de trabalho do time (web, CLI,
plugin para VS Code e MCP). O plugin do VS Code saiu do escopo de 2026.2 por decisão do PO em
[07/10/2026](/docs/reunioes/reunioes-po/ata-po-07-10).

## Escopo

O escopo do semestre foi fechado na [Lean Inception](/docs/lean-inception/visao-geral):

- **MVP 1 (Release 1):** estabilização do ecossistema, CI/CD confiável, fim do
  Grafana e primeira versão do cálculo de dívida técnica.
- **MVP 2 (Release 2):** suporte a repositórios do GitLab, novas visualizações
  nativas e consolidação dos gráficos gerenciais.
- **MVP 3 (Release 3):** refinamento do modelo matemático, alertas de
  decaimento de qualidade e preparação para adoção contínua.
